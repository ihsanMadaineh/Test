# منصة أفق - صفحة هبوط متكاملة

صفحة هبوط عربية متجاوبة مبنية بتقنيات الويب القياسية (HTML5, CSS3, Vanilla JS) دون أي تبعيات خارجية.

## المميزات المضمنة
- **تصميم متجاوب بالكامل (RTL):** دعم كامل للغة العربية مع قائمة جوال مخصصة.
- **الوضع الليلي والنهاري:** تبديل سلس مع حفظ تفضيل المستخدم في `localStorage`.
- **عداد إحصائيات متحرك:** عرض حي للأرقام الرئيسية عند تحميل الصفحة.
- **مبدّل خطط الأسعار:** التبديل الفوري بين الدفع الشهري والسنوي مع حساب الخصم.
- **قسم الأسئلة الشائعة (FAQ Accordion):** عرض تفاعلي للإجابات.
- **زر العودة للأعلى ونموذج اشتراك تفاعلي.**

## هيكل الملفات
- `index.html`: البنية الدلالية للصفحة والأقسام.
- `styles.css`: متغيرات الألوان، التنسيقات المتجاوبة، وتنسيقات الوضع الليلي.
- `main.js`: التفاعلات البرمجية وحفظ الحالة.
