# منصة أفق | Ufug Platform Landing Page

صفحة هبوط ثنائية اللغة (العربية / الإنجليزية) مبنية بتقنيات الويب القياسية (HTML5, CSS3, Vanilla JS) دون أي تبعيات خارجية.

## المميزات المضمنة
- **دعم ثنائي اللغة (AR / EN):** تبديل فوري بين العربية (`RTL`) والإنجليزية (`LTR`) مع حفظ اللغة المختارة في `localStorage`.
- **الوضع الليلي والنهاري:** تبديل سلس مع حفظ تفضيل المظهر.
- **عداد إحصائيات متحرك:** عرض حي للأرقام الرئيسية عند تحميل الصفحة.
- **مبدّل خطط الأسعار:** التبديل الفوري بين الدفع الشهري والسنوي مع حساب الخصم.
- **قسم الأسئلة الشائعة (FAQ Accordion) ونموذج اشتراك تفاعلي.**

## هيكل الملفات
- `index.html`: البنية الدلالية للصفحة ومفاتيح الترجمة (`data-i18n`).
- `styles.css`: متغيرات الألوان، الخصائص المنطقية (`inset-inline`) لدعم الاتجاهين، وتنسيقات الوضع الليلي.
- `main.js`: قاموس الترجمة، التفاعلات البرمجية، وحفظ الحالة.
